# @vexa-video/ffmpeg

FFmpeg/ffprobe planning and execution backend for Vexa Video SDK. Most applications should use `@vexa-video/sdk` instead of importing this backend directly.

The project-composition backend executes ordered programmable image/video effects for blur, brightness, contrast, saturation, hue, grayscale, sepia, deterministic noise, vignette, shadow, and glow. Shadow/glow use explicit split/mask/blur/overlay compositor branches with transparent bounds padding and position compensation. The backend executes shared programmable fade, slide, and wipe contracts with frame-to-second conversion at the project FPS plus linear/ease-in/ease-out/ease-in-out timing. Fade and wipe apply after effects and clip opacity; slide composes an easing-aware canvas-span offset with the authored overlay position. Transition-bearing text renders on an isolated transparent full-canvas layer, and renderer-materialized shapes/fills/solids reuse the normal image path. Legacy timeline xfade/wipe support remains intact. Non-normal blend modes with programmable slide/wipe and the programmable push/zoom/iris families remain explicit fail-closed paths until their dedicated graphs are implemented.
