# @vexa-video/ffmpeg

FFmpeg/ffprobe planning and execution backend for Vexa Video SDK. Most applications should use `@vexa-video/sdk` instead of importing this backend directly.

The project-composition backend executes ordered programmable image/video effects for blur, brightness, contrast, saturation, hue, grayscale, sepia, deterministic noise, vignette, shadow, and glow. Shadow/glow use explicit split/mask/blur/overlay compositor branches with transparent bounds padding and position compensation. The backend executes shared programmable fade, slide, wipe, zoom, and circular iris contracts with frame-to-second conversion at the project FPS plus linear/ease-in/ease-out/ease-in-out timing. Fade and wipe apply after effects and clip opacity; slide composes an easing-aware canvas-span offset with the authored overlay position; zoom scales the completed visual layer from/to a near-zero safe floor while preserving the authored center; iris applies a centered radial alpha mask whose fully-open radius reaches the layer corners. Transition-bearing text renders on an isolated transparent full-canvas layer, and renderer-materialized shapes/fills/solids reuse the normal image path. Programmable push uses a separate paired-motion graph for exactly two eligible overlapping full-canvas video clips: the previous and incoming clips move oppositely across a transparent transition stage, with exact frame-derived overlap and easing. Legacy timeline xfade/wipe support remains intact. Scene-leaf/image/text push, unsupported push layouts, animated-transform/non-normal-blend zoom combinations and non-normal blend modes with programmable slide/wipe/iris remain explicit fail-closed paths.
