# @vexa-video/ffmpeg

FFmpeg/ffprobe planning and execution backend for Vexa Video SDK. Most applications should use `@vexa-video/sdk` instead of importing this backend directly.

The project-composition backend executes ordered programmable image/video effects for blur, brightness, contrast, saturation, hue, grayscale, sepia, deterministic noise, vignette, shadow, and glow. Shadow/glow use explicit split/mask/blur/overlay compositor branches with transparent bounds padding and position compensation. The backend also executes the shared programmable fade contract with frame-to-second conversion at the project FPS and linear/ease-in/ease-out/ease-in-out alpha expressions after effects and clip opacity. Transition-bearing text renders on an isolated transparent full-canvas layer, and renderer-materialized shapes/fills/solids reuse the normal image path. Legacy timeline xfade/wipe support remains intact; programmable slide/wipe/push/zoom/iris stay explicit fail-closed paths until their spatial/mask execution graphs are implemented.
