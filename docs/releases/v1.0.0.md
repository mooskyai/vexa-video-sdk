Version 1.0.0 is the first source release of Vexa Video SDK, a typed media-processing toolkit for Node.js and TypeScript.

The repository contains seven versioned packages under `@moosky-video`: `core`, `ffmpeg`, `sdk`, `angular`, `ai`, `editor`, and `cli`. They cover media composition and editing, audio and captions, adaptive streaming, hardware-aware encoding, jobs and storage, Angular integration, AI extension contracts, and timeline editor helpers.

Requires Node.js 24.21.0 or newer and FFmpeg for media execution. npm publication is handled separately from this GitHub source release.
