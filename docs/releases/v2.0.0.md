# Vexa Video SDK 2.0.0

Released **2026-10-17**.

Version 2 turns Vexa from a deterministic media SDK into a broader programmable-video platform while preserving the same planning, browser-safety and execution principles.

## Highlights

- code-defined compositions with deterministic frame/time semantics;
- React authoring and framework-neutral browser playback;
- TypeScript/TSX bundling and Node composition rendering;
- local Studio development workflow with hot reload;
- shapes, effects, transitions, fonts and composition captions;
- GIF, waveform and sound-effect integrations;
- browser/WebCodecs rendering contracts;
- validated parameterized templates and reusable assets;
- hosted composition rendering contracts;
- CLI and MCP/agent composition workflows;
- deterministic visual/runtime regression tooling;
- synchronized eighteen-package release and cross-platform acceptance.
